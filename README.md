## 🎬 `spotlight: OneTake`

<table>
<tr>
<td width="62%" valign="top">

**The actor's self-tape audition studio**, built natively for both platforms. It covers the whole audition: scan the sides, run lines, film the takes, check them, and package the tape for casting.

- 🎭 **Voice-follow teleprompter** that scrolls as you speak, using on-device speech recognition
- 🎥 **Filming HUD** with a 3-2-1 slate countdown, exposure lock, eye-line grid and hold-to-stop
- ⭐ **Automated tape check** for framing, eye-line and audio clipping before you send
- 📦 **One-tap export** presets for Actors Access, Casting Networks and Spotlight
- 🔒 **Private by default**: all media stays on the device until you export it

</td>
